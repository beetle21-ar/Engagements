Internet and Web Definitions - Aria Wirastyo

  • Internet

    • Internet is a huge network that connects connected devices to enable them to communicate.

  • Web

    • Web is a system where documents and resources can communicate via internet.

  • How are the Internet and Web different?

    • The internet is the hardwares that are communicating and making network, but web is collection of information that run on that network.

  • ASCII and Unicode

    • ASCII and Unicode are standard encoding systems where computer can store numbers, texts, or symbols by assigning numbers to them.

  • What is UTF-8

    • UTF-8 is a variable-length encoding system that translates a character into a binary code.
